SIMPL_R Liquid Web Edition v0.23.13-web.1

Serve this folder from any HTTPS static host (GitHub Pages or Cloudflare Pages).
From the project root: python3 -m http.server 8000 --directory web
On localhost: http://localhost:8000

Click ENABLE AUDIO to unlock your browser's AudioWorklet and start its local C++ WebAssembly DSP.
The included synthetic demo plays without any sample files.

Ported from v0.23.13: PITCH performance macro, DIRECTION action pad with 6 directions,
COLOR attack 0-65%, restored MOTION mapping, faster live liquid-grain rendering.

The visitor's samples and recordings never leave their browser.
